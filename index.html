Khắc Phục Lỗi Google Sheet Không Nhận Dữ Liệu

Nguyên nhân: Quyền truy cập bị chặn (Lỗi 403 Forbidden)

Tại sao gửi báo thành công mà trong Google Sheet không có?

Hệ thống đã gửi request kiểm tra tới Web App URL và Google phản hồi: "Truy cập bị từ chối (403 Forbidden)". Điều này xảy ra do khi bạn bấm Triển khai (Deploy) trên Google Sheet, bạn chưa cấp quyền cho "Bất kỳ ai (Anyone)" truy cập!

Các bước sửa quyền trên Google Sheet (Chỉ 1 phút):

  1. Mở file Google Trang Tính (Google Sheet) của bạn.
  2. Trên thanh menu, chọn Tiện ích mở rộng (Extensions) > Apps Script.
  3. Ở góc trên bên phải, bấm nút Triển khai (Deploy) > chọn Quản lý bản triển khai (Manage deployments) (hoặc Triển khai mới).
  4. Bấm biểu tượng cây bút chì (Chỉnh sửa) hoặc tạo bản mới:

    • Thực thi dưới dạng (Execute as): Chọn Tôi (Me / email của bạn)

    • Ai có quyền truy cập (Who has access): BẮT BUỘC CHỌN Bất kỳ ai (Anyone)

  5. Bấm Triển khai (Deploy), bấm cấp quyền nếu Google hỏi, sau đó Sao chép Web App URL mới.
  6. Quay lại trang này, dán URL mới vào ô Cài đặt và bấm Lưu cấu hình.

Mã nguồn Google Apps Script chuẩn (Nếu bạn cần tạo mới): 

function doPost(e) {
  try {
    var sheet = SpreadsheetApp.getActiveSpreadsheet().getActiveSheet();
    if (sheet.getLastRow() === 0) {
      sheet.appendRow(["Thời gian", "Họ và tên", "Ngày sinh", "Khóa học", "Giáo viên", "Ghi chú"]);
    }
    var data = JSON.parse(e.postData.contents);
    sheet.appendRow([
      new Date(),
      data.fullname || "",
      data.dob || "",
      data.course || "",
      data.teacher || "",
      data.note || ""
    ]);
    return ContentService.createTextOutput(JSON.stringify({ result: "success" }))
      .setMimeType(ContentService.MimeType.JSON);
  } catch (err) {
    return ContentService.createTextOutput(JSON.stringify({ result: "error", error: err.toString() }))
      .setMimeType(ContentService.MimeType.JSON);
  }
}

function doGet(e) {
  return ContentService.createTextOutput(JSON.stringify({ status: "online", result: "success" }))
    .setMimeType(ContentService.MimeType.JSON);
}

Hướng Dẫn Nhanh

1. Đăng ký nhiều tên: Điền Khóa học & Giáo viên 1 lần, sau đó bấm + Thêm học viên hoặc bấm Dán Nhanh Danh Sách để dán nhiều người cùng lúc.

2. Xem lịch sử: Bấm vào mục Lịch Sử Đăng Ký trên thanh header để xem tất cả các đợt đã nộp, xuất file Excel hoặc in danh sách.

3. Lỗi không vào Google Sheet: Bấm vào biểu tượng Cài đặt trên góc phải để kiểm tra kết nối và xem hướng dẫn mở quyền "Anyone".
